# オーダーシステム

バンドTシャツを品番・写真で照合し、PCで注文をまとめるアプリです。

- **公開ページで試す**　[商品一覧・テスト注文](https://k-r-base425.github.io/order-system/) で半袖175品番・長袖75品番を検索できます。「注文を作る」で選んだ商品は、点数を確認してテスト注文として保存できます。「注文履歴」で同じブラウザから開けます。
- 2026年11月20日に写真の重複を整理して再採番しました。過去の注文書は [旧品番と新品番の対応表](品番対応表.csv) で照合できます。
- **初回注文書を見る**　[見積書と写真付き注文書の試算PDF](検証見本/PO-0001_見積書と写真付き注文書_試算.pdf) は全4ページです。
- **注文を作る**　注文アプリはMacでローカル実行します。Python 3、Pillow、ReportLabを準備し、半袖・長袖フォルダーに元の品番付きJPEGを用意して、初回に `python3 app.py --source "/path/to/photos" --open` を実行します。下書き・注文履歴はそのMacのSQLite台帳に保存されます。

見積書・請求書には [帳票ひな型](帳票ひな型.xlsx) を使います。[操作手順](使い方.md)
